# IDC 日志检查工具批量文件夹检查设计

**日期：** 2026-08-24  
**状态：** 用户已确认聊天版设计，等待书面设计确认  
**适用程序：** Avalonia 与 WinForms 两个 Windows 11 x64 前端

## 目标

把现有单文件夹检查升级为批量检查。用户可以一次选择或拖入多个文件夹，程序按顺序分别检查，并用容易理解的主从界面展示批次汇总和每个文件夹的独立结果。

现有 62 个设备目录、3,660 个 TXT 文件名、空文件错误和一行文件提示等检查规则保持不变，两个界面继续共用同一套核心规则。

## 输入行为

### 文件夹选择

- Avalonia 使用支持多选的文件夹选择器。
- WinForms 使用 Windows 原生多选文件夹对话框。
- 一次选择可以包含一个或多个文件夹。

### 拖放

- 用户可以把一个或多个文件夹拖到主窗口任意位置。
- 拖放经过窗口时显示明显的可放置状态。
- 放下后与文件夹选择器产生相同的待检查批次。

### 输入规范化

- 只接收当前存在的文件夹。
- 普通文件和无效路径不进入检查队列，但在界面中显示跳过数量和逐项原因。
- 同一文件夹重复出现时只保留一次，并显示自动去重提示。
- Windows 路径去重不区分大小写；其他平台的开发测试按所在文件系统规则处理。
- 再次选择或拖入时，新批次替换旧批次并清空旧检查结果。
- 输入完成后不自动开始检查，用户仍需点击“开始检查”。

## 批量扫描模型

新增 UI 无关的批量检查层，负责：

1. 接收规范化后的文件夹路径列表。
2. 按用户提供的顺序逐个调用现有 `DirectoryScanner`。
3. 汇报“当前第几个文件夹 / 总数”、当前文件夹名称和内部目录进度。
4. 保存每个文件夹独立的 `ScanResult`。
5. 某个文件夹产生检查错误或扫描异常时记录该项结果，并继续检查后续文件夹。
6. 生成批次级统计和导出数据。

批次状态分为：

- 完全通过：错误数为 0，提示数为 0。
- 通过但有提示：错误数为 0，提示数大于 0。
- 不通过：错误数大于 0。

批次汇总包含：总文件夹数、已完成数、完全通过数、有提示数、不通过数、错误总数和提示总数。

## 界面布局

### 顶部区域

- 保留产品标题和 62 / 3,660 基准标识。
- 路径输入改为批次摘要，例如“已选择 5 个文件夹”。
- 提供“选择文件夹”“开始检查”和清晰的拖放提示。
- 显示批次总数、完全通过、有提示、不通过四项统计。
- 进度文字显示“正在检查第 2/5 个：文件夹名称”，进度条同时反映批次进度。

### 结果区域

采用左侧文件夹列表、右侧当前文件夹详情的主从布局。

左侧每项显示：

- 文件夹名称。
- 完整路径或可查看的路径说明。
- 当前状态：等待检查、检查中、完全通过、有提示、不通过。
- 错误数和提示数。

如果不同父目录下存在同名文件夹，使用完整路径区分。

右侧显示当前选中文件夹的：

- 总体结论。
- 设备目录实际数 / 62。
- TXT 文件实际数 / 3,660。
- 错误数和提示数。
- 全部、只看错误、只看提示筛选。
- 问题明细、复制明细和打开文件位置。

扫描完成后默认选择第一个不通过的文件夹；如果没有错误，则选择第一个有提示的文件夹；全部完全通过时选择第一个文件夹。

## 输入提示与错误处理

- 混合拖入时，有效文件夹继续进入批次，文件和无效路径逐项列入跳过说明。
- 全部输入均无效时不替换当前批次，并显示“没有找到可检查的文件夹”。
- 批次已替换但尚未扫描时，导出按钮保持不可用。
- 扫描期间禁用再次选择、拖放和开始检查，避免批次被中途替换。
- 单个目录在开始前被删除时，沿用现有“所选文件夹不存在”错误，并继续后续项目。
- 界面异常消息使用中文，不显示技术堆栈。

## 报告导出

提供两个按钮：

### 导出全部结果

生成一份 UTF-8 中文批量报告，内容依次为：

1. 批次路径数量和总体统计。
2. 跳过或去重的输入说明。
3. 每个文件夹的完整路径、独立结论和统计。
4. 每个文件夹的错误及提示明细。

文件夹之间使用明显分隔线，保证打印和转发后仍易于阅读。

### 导出当前结果

继续使用现有单文件夹中文报告格式，只导出右侧当前选中的文件夹结果。

## 代码边界

- `Checker.Core`：新增批次输入规范化、批量协调、批次统计和批量报告，不引用任何 UI 框架。
- `Checker.Avalonia`：实现多选、拖放、主从布局和批次视图模型。
- `Checker.WinForms`：实现 Windows 原生多选文件夹对话框、拖放、主从布局和批次界面。
- 两个前端不得复制目录和 TXT 检查规则。
- 原始日志目录始终只读。

## 自动化测试

新增测试覆盖：

- 单文件夹输入仍正常工作。
- 多文件夹保持输入顺序逐个检查。
- 重复路径去重。
- 普通文件和无效路径被跳过并保留说明。
- 全部输入无效时不替换现有批次。
- 混合输入中的有效文件夹继续检查。
- 某个文件夹不通过不阻止后续文件夹。
- 批次三类状态和汇总数字准确。
- 默认选中优先级正确。
- 导出全部报告和导出当前报告内容正确。
- Avalonia 与 WinForms 的显示适配使用同一个批次结果语义。
