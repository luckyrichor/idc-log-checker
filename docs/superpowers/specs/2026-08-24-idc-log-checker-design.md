# IDC 日志完整性检查工具设计

## 目标

为完全不熟悉计算机操作的用户提供 Windows 11 x64 桌面工具。用户只需选择一个巡检结果目录并点击“开始检查”，程序便依据当前目录中已经确认的 62 个设备目录和每个目录下的 TXT 文件名基准，给出清晰、可导出的检查结论。

## 最终交付

测试阶段提供两个互为备选的 Windows 自包含单文件程序：

- `IDC日志检查工具_Avalonia.exe`
- `IDC日志检查工具_WinForms.exe`

两个 EXE 都内置同一份基准清单和同一套检查核心，无需安装 .NET、Python、数据库、DLL 或配置文件。Windows 首次运行未签名 EXE 时可能显示“未知发布者”；单文件运行时可能在 `%TEMP%` 产生运行缓存，这不属于安装。

## 项目与依赖边界

项目根目录固定为：

`/Users/lc/Desktop/work/62监控/IDC日志检查工具_Win11/`

便携式 .NET SDK、NuGet 包、缓存和临时文件全部位于项目的 `.tools/` 下。不得使用 Homebrew，不修改全局 PATH，不向 `/usr/local`、`/opt/homebrew` 或系统 Applications 目录安装内容。

## 架构

项目分为四部分：

1. `Checker.Core`：读取内置基准、扫描目录、分类问题、生成报告。它不依赖任何界面框架。
2. `Checker.Avalonia`：跨平台中文界面，可在 Mac 上实际运行和检查当前日志，也可发布 Windows x64 EXE。
3. `Checker.WinForms`：Windows 原生中文界面，复用 `Checker.Core`，发布为 Windows x64 EXE。
4. `Checker.Tests`：自动构造测试目录，验证核心检查规则和报告输出。

基准清单由 `LogRst_20260823_2359` 生成，并与 `LogRst_20260801_0004` 再次交叉核对。两批目录及文件名已经确认完全一致。基准作为嵌入资源编译进两个 EXE。

## 检查流程

1. 用户通过文件夹选择窗口选择待检查目录。
2. 程序验证目录存在且可读取。
3. 对顶层设备目录使用区分大小写的精确名称比较：
   - 缺少目录：错误。
   - 多出目录：错误。
   - 仅大小写不同：错误，并成对显示“应为”和“实际为”。
4. 对存在的预期设备目录逐一检查其直接子文件：
   - 缺少预期 TXT：错误。
   - 多出 TXT：错误。
   - 仅大小写不同：错误。
   - 非 TXT 文件：提示。
   - 嵌套子目录：提示，不递归纳入基准比较。
5. 对所有存在的预期 TXT 检查内容：
   - 0 字节、仅 BOM、或没有任何有效字符：错误，显示“文件无有效内容”。
   - 只有一个逻辑行：提示，显示该行的安全截断预览。
   - 无法读取：错误，包含系统异常信息。
6. 汇总检查总数、错误数和提示数，并允许查看详细列表和导出 UTF-8 TXT 报告。

## 结果表达

- 红色“错误”：检查结构不符合基准或文件不可用，整体结论为“不通过”。
- 黄色“提示”：结构可能正确，但存在需要人工关注的情况；不单独导致结构检查失败。
- 绿色“通过”：没有错误。存在提示时显示“检查通过，但有提示需要关注”。

每条明细包含级别、类别、设备目录、文件路径、期望值、实际值和通俗说明。界面提供“只看错误”“只看提示”“查看全部”、复制明细和导出报告。

## 界面

两个界面保持相同信息结构：

- 顶部：标题、用途说明。
- 选择区：路径输入框、“选择文件夹”、“开始检查”。
- 摘要区：总体结论、目录计数、TXT 计数、错误数、提示数。
- 详情区：可筛选表格，双击或选择后显示完整说明。
- 底部：“导出报告”“复制选中内容”“打开所选文件位置”。

扫描在后台执行，扫描期间禁用重复点击并显示进度，界面不能长时间无响应。

## 测试

`test/` 下包含自动化测试、生成的测试目录和结果报告。至少覆盖：标准正确、目录缺失/多出/大小写错误、TXT 缺失/多出/大小写错误、空文件、BOM/空白文件、单行文件、多错误并存、非 TXT、嵌套目录、无法读取、错误层级、中文/空格/长路径、报告导出和两批真实日志扫描。

Mac 上必须通过核心自动化测试、Avalonia 界面实际运行、两批真实日志扫描、Windows 两套 EXE 交叉编译和单文件产物检查。WinForms 实际界面以及两个 EXE 在 Windows 11 上的启动行为由用户最终验证。

## 非目标

- 不判断设备业务状态是否正常。
- 不比较两次日志的内容差异。
- 不修改、移动或删除待检查目录中的任何文件。
- 不联网更新基准或程序。
